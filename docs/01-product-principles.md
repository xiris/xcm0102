# Product Principles

## Preserve from CM0102

### 1. Speed over spectacle
CM0102 is fast. Players can advance days quickly, watch matches through text commentary, and finish seasons without being slowed by presentation. A modern version should stay text/table/stat-first by default. Optional visualizations are welcome only if they do not slow the core loop.

### 2. Depth without bloat
The original has many systems — tactics, training, transfers, contracts, staff, scouting, board, media, injuries, suspensions, competitions, history — but most are compact and action-driven. Modern systems should be optional where possible and should not become mandatory meeting simulators.

### 3. Emergent stories
The drama comes from transfers, injuries, morale, job insecurity, bargains, wonderkids, tactical gambles, board pressure, and long careers. The game should remember events and make success/failure part of a continuing manager story.

### 4. Database as playground
Recruitment is a treasure hunt. Search, scouting, shortlists, contracts, and hidden knowledge are not utilities; they are core gameplay. Support custom, generated, modern, and historical databases.

### 5. Tactical expression
The original supports simple tactics and deep WIB/WOB positioning. Preserve both layers: quick presets for casual players, deep editor for obsessive players. Explain consequences through coach/scout reports rather than exposing exact formulas.

### 6. Mystery without unfair opacity
Hidden attributes and community theories are part of the charm. But a modern version should let users infer hidden traits from reports, history, behavior, and performance patterns.

### 7. Online fairness
The server should own truth and simulation. Managers should have private state: tactics before lock, shortlist, notes, scouting knowledge, private bids, and reports. World progression needs readiness, holiday mode, host/admin control, or scheduled ticks.

## Modern gaps to fix

- No compatibility hacks, disc mounting, patch confusion, or save corruption anxiety.
- Better table UX, search, filters, keyboard shortcuts, responsive layout, and saved views.
- Better onboarding for tactics, training, scouting, transfers, and staff.
- Real online lobbies, invitations, presence, ready states, holiday delegation, and admin tools.
- Better exploit handling for competitive modes.
- First-class modding/data tooling: editor, validation, import/export, database versions.
- Event/audit logs for multiplayer trust and debugging.

## Product stance

The game should feel like:
- one more match;
- I found a bargain nobody else saw;
- my tactical tweak changed the season;
- the board might sack me, but another club may hire me;
- this online league matters because other humans are competing in the same world.

It should not feel like:
- a spreadsheet clone with no soul;
- a modern FM clone overloaded by mandatory meetings;
- a pay-to-win squad builder;
- a perfect-information optimizer where the best player/tactic is always obvious.
