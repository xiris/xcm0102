# Domain Model

## Top-level entities

### GameWorld
One save/server world.

Fields:
- id, name, owner/admins;
- current date and phase;
- database version;
- selected leagues and simulation modes;
- progression mode;
- random seed;
- rules/balance preset;
- visibility/fog-of-war settings;
- status: setup, active, paused, archived.

### User and Manager
User is the real account. Manager is the in-world career persona.

Manager fields:
- identity and nationality;
- reputation;
- manager points;
- career history;
- current club or unemployed;
- employment contract/status;
- preferences/statistical tendencies;
- private notes, shortlist, and knowledge.

### Club
Fields:
- identity, nation, reputation;
- board/chairman;
- finances;
- stadium;
- squads: senior/reserve/youth;
- staff;
- transfer/wage budgets;
- expectations;
- history/records.

### Nation, League, Competition
Rule-driven objects defining participants, schedules, points, tiebreakers, promotion/relegation, playoffs, qualification, prize money, substitutions, registrations, foreign limits, work permits, cup-tied rules, discipline, and transfer windows.

## People

### Player
Fields:
- identity, DOB, nationality, second nationalities, languages;
- club/squad/contract;
- positions/sides/footedness;
- visible attributes;
- hidden attributes;
- current ability/potential ability if used internally;
- condition, fatigue, match sharpness;
- morale and personality state;
- injuries/suspensions/availability;
- form and ratings;
- career stats;
- relationships;
- transfer status and squad role;
- manager/club-specific knowledge visibility.

### Staff
Roles:
- assistant manager;
- coach;
- scout;
- physio.

Fields:
- role capabilities;
- attributes;
- contract;
- assignments;
- reports generated;
- reputation and relationships.

## Tactical entities

### Tactic
Fields:
- name;
- formation;
- team instructions;
- player instructions;
- set-piece assignments;
- marking assignments;
- with-ball zone positions;
- without-ball zone positions;
- saved variants;
- version/history.

### MatchPlan
Per-match selected tactic plus lineup, bench, captain, penalty order, set-piece takers, and tactical variants.

## Operational entities

### NewsItem
Fields:
- recipients;
- category;
- title/body template;
- source entity;
- created date;
- visibility: private, club, world;
- actions: accept/reject/negotiate/appeal/respond/view;
- deadline/expiry;
- outcome effects.

### Report
Generated by scouts, coaches, physios, assistant, or opposition analysts.

Fields:
- subject;
- author;
- confidence;
- revealed attributes/ranges;
- qualitative tags;
- recommendation;
- generated date;
- stale date.

### TransferBid / ContractOffer / LoanOffer
Asynchronous negotiation state with history.

TransferBid fields:
- selling club, buying club, player;
- fee;
- installments;
- clauses;
- exchange players;
- public/private;
- requested date;
- status;
- counteroffers/responses.

ContractOffer fields:
- wage;
- length;
- bonuses;
- release clauses;
- role/status;
- refusal reasons;
- status.

LoanOffer fields:
- duration;
- wage share;
- cup eligibility;
- recall/future option if used;
- status.

### TrainingRoutine / TrainingAssignment
Fields:
- target group/player;
- intensity by category;
- coach assignments;
- start/end;
- attribute deltas;
- fatigue/injury risk effects.

### HeadToHeadLobby / VersusMatch
A lightweight competitive wrapper around the match engine, separate from career/calendar saves.

Fields:
- creator/invited users;
- rules preset;
- database version;
- selected teams or draft squads;
- team/squad snapshots;
- private lineup/tactic submissions;
- lock state;
- match seed;
- match result/report;
- rematch/series state.

### Tournament
A collection of head-to-head matches.

Fields:
- format: single elimination, double elimination, round robin, Swiss, league, best-of-series;
- entrants;
- seeding;
- rules preset;
- deadlines;
- bracket/group/table state;
- admin actions;
- result confirmations;
- persistent injuries/cards/condition setting.

## Private vs public state

Public:
- fixtures/results;
- tables;
- public bids;
- completed transfers;
- public player profile data;
- manager jobs/sackings/honours.

Club-private:
- finances if hidden from rivals;
- tactical presets;
- staff assignments;
- coach/physio/scout reports;
- internal morale issues until leaked.

Manager-private:
- notes;
- shortlist;
- scouting knowledge;
- private bids;
- nicknames;
- planned tactics and lineups before lock.

Server-only truth:
- hidden attributes;
- exact CA/PA if used;
- random seed state;
- exact match-engine calculations;
- unobserved outcomes;
- anti-cheat/audit logs.

## Event-driven architecture

Model gameplay as commands producing events.

Examples:
- SubmitTransferBid -> TransferBidSubmitted -> ClubRespondedToBid.
- AssignScout -> ScoutAssignmentCreated -> ScoutReportReady.
- ContinueWorld -> matches simulated, injuries updated, news generated.
- ChangeTactic -> TacticUpdated.

Benefits:
- deterministic online simulation;
- auditability;
- notifications;
- debugging/replay;
- clean async UI clients.
